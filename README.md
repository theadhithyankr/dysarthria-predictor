# Dysarthria Predictor

Speech-based dysarthria detector with audio preprocessing, feature extraction, and machine learning classification.

## Key Features
- Speech-based dysarthria detector with audio preprocessing, feature extraction, and machine learning classification
- Backend/runtime files are documented alongside the frontend or app layer when the repository includes them.

## Tech Stack
- Python
- Flask

## Project Structure
- Key files: app.py, requirements.txt.

## Setup and Run
```bash
git clone https://github.com/theadhithyankr/dysarthria-predictor.git
cd dysarthria-predictor
python -m venv .venv
.\\.venv\\Scripts\\Activate.ps1
pip install -r requirements.txt
python app.py
```
